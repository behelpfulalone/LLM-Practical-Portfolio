# Activity Outcomes

The selected challenge was the Busy Student. The resulting product concept, CampusFlow AI, targets university students who need to coordinate academic and personal commitments.

The activity produced a named product, target-user definition, six proposed features and a three-screen visual prototype. The proposed workflow is: enter timetable and tasks, request an AI schedule, validate conflicts, review the plan, and track completion.

The prototype is available [here](../screenshots/campusflow-prototype.png). No functional application or user testing was conducted.
